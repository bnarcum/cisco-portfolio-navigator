Family node icon styles

Six treatments for the round family/product icons used in the Families and All Products views — from today's flat fill up to glass, neumorphic, glossy, metallic, and holographic finishes. Same three pillar colors throughout so you can compare in context.

👉 Hover any circle to see the interactive state. Recommended pick marked below.

0 · Current (baseline)

Today

Flat solid fill, white icon, no depth. Clear and fast to scan, but every node reads the same regardless of state — nothing signals "clickable" beyond cursor and hover scale.

1 · Frosted glass

Recommended

Translucent gradient fill with a soft top highlight (glass "cap"), inset shadow for depth, and a colored glow that matches the pillar. Reads as tactile and modern without losing the accent color coding — closest to macOS/visionOS glass idioms that pair well with the app's existing dark UI and cyan glow accents.

2 · Soft UI (neumorphic)

Subtle

Icon buttons carved from the dark surface itself — icon glows in the pillar color instead of a colored fill. Very calm and premium, but color-coding is weaker at a glance across a dense grid; better for a focused detail panel than a 26-node family grid.

3 · Glossy gradient + glow ring

High energy

Keeps the bold solid-color read from today, adds a diagonal gloss highlight and an outer glow ring in the same hue. Good middle ground if glass feels too subtle — still very "at-a-glance" scannable, with more visual richness on hover.

4 · Metallic bevel

Hardware feel

Brushed-metal button with a small colored LED indicator at the base instead of a full color fill — evokes physical Cisco hardware (switches, APs). Distinctive, but loses fast color scanning since the pillar color shrinks to a tiny accent dot.

5 · Holographic / iridescent

Most creative

Slow animated conic gradient shifts hue subtly, like an anodized or holographic finish. Eye-catching for a hero moment (overview hub, kiosk attract) — probably too busy for 26+ nodes in a dense grid, so best reserved for a small number of "featured" or newly-acquired products.

Where this lives in code: today's nodes are SVG circles (.mc / .gr / .mring) rendered by D3 around index.html:5718, not CSS divs — so shipping any of these would mean moving fill from a flat attr("fill", …) to SVG <radialGradient>/<filter> defs (glass, glow, holo) or swapping the family/all-products grid to HTML tiles with real CSS backdrop-filter (glass, neumorphic) for the crispest result. Also check contrast against the existing per-node hover ring/scale interaction so effects don't double up.
